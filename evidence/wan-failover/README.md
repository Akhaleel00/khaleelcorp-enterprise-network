# WAN Failover Validation

This directory contains operational evidence validating dual-WAN failover functionality within the KhaleelCorp Enterprise Network Lab.

Validation included:

* primary WAN routing verification
* internet connectivity testing
* Router-A failure simulation
* backup route activation
* Router-B NAT validation
* routing convergence testing
* primary path restoration

Failover testing was performed by simulating Router-A internal uplink failure and verifying successful internet recovery through Router-B.
